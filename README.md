# Site do app do aluno

Somente os arquivos já montados do app do aluno (gerados por `scripts/publicar-site-aluno.sh` no repositório privado do sistema).
Não contém código-fonte, dados de alunos nem chaves secretas. A chave do banco que aparece no pacote é a chave pública,
feita para ficar no navegador; quem protege os dados são as regras do banco.
